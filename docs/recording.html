Takes and comparison

Record the raw and the result.

Sonus writes two WAV files for every take: the untouched microphone and the processed voice. Play them back through the same headphones and compare the difference immediately.

Recording a take

Recording is part of the same real-time path as monitoring and the virtual microphone. There is no separate export step.

  1. Start the engine. Press LIVE and make sure the input meter moves.
  2. Press Record a take. The timer starts and both files begin filling.
  3. Speak. The virtual microphone and headphone monitor continue to work while recording.
  4. Press Finish take. Sonus closes both WAV files and adds the take to the list.
Record a clean reference first. A raw take is useful for comparison and for recovering a performance if the processing is too strong. You can always process it again.

Comparing raw and processed

Playback goes through the selected headphones, not the Windows default device. That keeps the comparison consistent with what you were monitoring.

Take row buttons

  • Play icon — plays the processed version of that take.
  • RAW — plays the untouched microphone version.
  • Trash — discards the take and deletes both WAV files.

Transport

Select a take to reveal the transport underneath the list. The outer play button pauses or resumes. The slider seeks. The PROCESSED / RAW button switches versions without leaving the transport.

If the processed version is silent, play the RAW version. If RAW is also silent, the microphone did not capture any audio. If only PROCESSED is silent, check the Clean threshold and whether a stage is bypassed or attenuated.

Managing takes

The Takes list keeps the most recent recordings, newest first. Each row shows the take number and duration.

  • Discard — deletes the raw and processed WAV files and removes the row.
  • Replay — selecting another take loads it for comparison.
  • Files — recordings remain ordinary WAV files even if you remove them from the list.

If a file is open in another application and cannot be deleted, Sonus removes the row and reports that the WAV may remain on disk.

Where files are stored

Each take is written to:

Documents\Sonus Recordings\Sonus_YYYY-MM-DD_HH-mm-ss_raw.wav
Documents\Sonus Recordings\Sonus_YYYY-MM-DD_HH-mm-ss_processed.wav

The files are 48 kHz, 16-bit mono WAV, suitable for editing in any audio application. Presets and preferences live under %LOCALAPPDATA%\Sonus.

Raw and processed stay in sync. Both files begin at the same moment and use the same sample rate, so they can be aligned in another editor without guesswork.
