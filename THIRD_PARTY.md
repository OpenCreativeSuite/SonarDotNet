Sonus.NET uses the following third-party components.

The desktop interface framework. See the [Donkeh UI repository](https://github.com/barely-sentient/donkeh-ui) for its licence and notices.

Audio device access, WASAPI interop, WAV writing and playback. NAudio is distributed under the MIT licence. See the [NAudio repository](https://github.com/naudio/NAudio).

## VB-CABLE

VB-CABLE is an optional virtual audio device by VB-Audio (Vincent Burel). It is **not bundled** with Sonus.NET. The setup sheet can download the official package from VB-Audio and run its official installer when the user asks it to. VB-CABLE is donationware; see [vb-audio.com/Cable](https://vb-audio.com/Cable/).

No VB-Audio driver files are stored in this repository.
